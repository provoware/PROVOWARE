PROVOWARE – LAIENANLEITUNG FÜR DAS GETEILTE INSTALLATIONSPAKET
Version: 0.1.0-dev / Baseline I006 / Transfer V1

WAS IST DAS?
Das große PROVOWARE-Paket wurde in kleinere, transportfreundliche Teilstücke geteilt.
Du musst die Teilstücke NICHT selbst zusammenfügen und NICHT einzeln entpacken.

DU BRAUCHST NUR:
1. PROVOWARE_INSTALLIEREN.sh
2. alle Dateien mit der Endung .pvpart

Lege diese Dateien gemeinsam in EINEN Ordner, zum Beispiel:
Downloads/PROVOWARE_I006/

ALLE BEFEHLE:

mkdir -p "$HOME/Downloads/PROVOWARE_I006_TRANSFER_V1"
cd "$HOME/Downloads/PROVOWARE_I006_TRANSFER_V1"
ls -lh PROVOWARE_INSTALLIEREN.sh PROVOWARE_I006_TRANSFER_V1.teil*.pvpart
chmod +x PROVOWARE_INSTALLIEREN.sh
bash PROVOWARE_INSTALLIEREN.sh

DANACH PRÜFEN:

cd "$HOME/PROVOWARE"
python3 WERKZEUGE/baseline_pruefen.py
cat TRANSFER/INSTALLATIONSNACHWEIS.json

OPTIONALER ZIELORDNER:

cd "$HOME/Downloads/PROVOWARE_I006_TRANSFER_V1"
PROVOWARE_ZIEL="$HOME/PROVOWARE_TEST" bash PROVOWARE_INSTALLIEREN.sh
cd "$HOME/PROVOWARE_TEST"
python3 WERKZEUGE/baseline_pruefen.py
cat TRANSFER/INSTALLATIONSNACHWEIS.json

GRÖSSEN:
- Gesamtpaket: 295,21 MB / 281,53 MiB.
- Teil 001–011: je 25,17 MB / 24,00 MiB.
- Teil 012: 18,39 MB / 17,53 MiB.
- Installer: 0,009 MB.
- Starter-ZIP: 0,006 MB.

AB START DES INSTALLERS LÄUFT ALLES AUTOMATISCH:
- alle Teilstücke werden gefunden,
- Größe und SHA-256 jedes Teilstücks werden geprüft,
- das Original-ZIP wird bytegenau zusammengesetzt,
- der SHA-256 des Gesamt-ZIPs wird geprüft,
- das ZIP wird vollständig auf Fehler geprüft,
- PROJEKTSTATUS.json und Baseline werden kontrolliert,
- eine vorhandene ~/PROVOWARE-Installation wird automatisch gesichert,
- der neue Stand wird nach ~/PROVOWARE installiert,
- bei einem Fehler nach der Sicherung wird automatisch zurückgerollt,
- ein INSTALLATIONSNACHWEIS.json wird angelegt,
- temporäre Dateien werden danach entfernt.

KEIN INTERNET ERFORDERLICH.
Nach dem Download der Dateien arbeitet die Installation vollständig offline.

WICHTIG:
Der aktuelle Stand I006 ist ein qualifiziertes Entwicklungsfundament.
Er ist noch nicht die fertige grafische PROVOWARE-Anwendung.

FEHLERFALL:
Das Skript bricht bei fehlenden, falschen oder beschädigten Teilstücken ab,
BEVOR eine bestehende Installation verändert wird.
