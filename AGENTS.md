# AGENTS.md

## Arbeitsmodus

- Deutsch verwenden.
- Pro Iteration genau ein Hauptziel bearbeiten.
- Vor Änderungen Baseline, Patchplan und Rückweg festhalten.
- Erst am Ende gezielt validieren.
- Neue Arbeit in `TODO.md` unter `PLAN_DELTA` registrieren.

## Iterationsablauf

`BASELINE -> VORANALYSE -> PATCHPLAN -> PRECHECK -> PATCH -> TEST -> POSTCHECK -> PLAN_DELTA -> UEBERGABE`

## Abbruch

- Bei unklarer Baseline, unklarer Datenintegrität oder fehlendem Rückweg nicht automatisch fortfahren.
