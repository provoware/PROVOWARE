# Workspace-Dokumentation 0.3.0

## Für Einsteiger

1. `PLAN_0.3.0.md` lesen – erklärt die gesamte Entwicklung in Reihenfolge.
2. `WORKSPACE_CONTRACT.md` lesen – enthält die verbindlichen Daten- und Verhaltensregeln.
3. `DECISIONS_0.3.0.md` lesen – dokumentiert getroffene Entscheidungen und deren Gründe.
4. `STATUS_0.3.0.md` lesen – zeigt den aktuellen Stand und die nächsten zwei Schritte.
5. `QA_0.3.0_A.md` lesen – enthält die Abnahme der aktuellen Vertragsphase.

## Für Entwickler

Die verbindliche Reihenfolge lautet:

`Vertrag -> State/Autosave/Reset -> Sichtbarkeit -> Resize -> Drag & Drop -> Responsive/Accessibility -> Release Gate`

Vor jedem Patch gelten zusätzlich die Regeln aus `AGENTS.md`.
