# Änderungsumfang 0.3.0-A

## Erlaubt

- Planungsdokumente
- Workspace-Vertrag
- Status/TODO
- Entscheidungs- und Abnahmedokumentation

## Nicht erlaubt

- HTML-Laufzeitänderungen
- CSS-Laufzeitänderungen
- JavaScript-Laufzeitänderungen
- neue Bibliotheken
- Versionsanhebung
- Drag & Drop
- Resize- oder Visibility-Code

Diese Grenze verhindert, dass während der Vertragsphase bereits ungetestete Bedienlogik entsteht.
